# Knowledge Bundle Update Log

## 2026-09-21

- **Fix (restore)**: `scripts/restore.sh` had two bugs, both inherited from upstream v0.2.0, both found by restoring the branch this repository publishes rather than by reading the script: it never created the output directory (`pixi-sandbox restore --output-path` refuses a missing path, and a fresh path is the normal case for the documented second argument), and its closing PATH block pointed at `$PWD/.pixi/...` instead of `$OUTPUT/.pixi/...`, so restoring anywhere except the repository root silently wired PATH back at the root. Fixed (`mkdir -p "$OUTPUT"`, `$OUTPUT` in the three PATH lines) and verified by restoring `sandbox/developer-linux-64` into a scratch directory outside the workspace: `doctor --verify` reported 13 816 blobs, 0 failures, and the restored tree then built, tested, and linted offline.
- **Airlock measured**: The published `sandbox/developer-linux-64` branch is 962.1 MiB — `dev` 471.8 MiB packed → 1948.3 MiB unpacked (61 blobs), `docs` 85.4 MiB → 333.6 MiB (40 blobs), helper tools 94.8 MiB, cargo vendor tree 310.1 MiB across 267 crates (32% of the payload). The Rust toolchain makes `dev` heavy; `cargo_vendor = false` is the lever if a bundle must shrink. With the project manifests copied into the restored tree, the whole workspace compiles offline in ~42 s (`cargo` warns that `proc-macro-error2 v2.0.1` will be rejected by a future Rust version — the `deny.toml` ignore in practice); `test`, `lint-rust` and `lint-toml` pass from the restored tree. "Airlock" means no *package* network, not no network at all: `deny` git-clones `RustSec/advisory-db` when its per-`CARGO_HOME` cache is cold, and `lint-actions` wants a Git repository with `.github/workflows` in it. Recorded in [pixi-sandbox](./landscape/pixi-sandbox.md).
- **Correction (knowledge hygiene)**: `.pixi-sandbox.toml` declares the `developer` bundle only, not `developer` and `release` — the earlier entry in this log and the L1 sketch in [pixi-sandbox](./landscape/pixi-sandbox.md) both said otherwise, and the stale "still planned" framing of the local install was replaced with the measured state.
