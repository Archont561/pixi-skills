- **Correction (sandbox publishing)**: The reusable publisher upstream cannot work for any caller. It checks the project out into `project/` and then runs `prefix-dev/setup-pixi` without `working-directory: project`, so `pixi install` finds no `pixi.toml` and the `plan` job fails before a matrix exists. Measured on the upstream repository: its last two publish-sandbox runs failed in ~10s at "Install Pixi (local mode)", and it has no `sandbox/*` branches. `publish-sandbox.yml` now consumes the same pinned composite actions and the same SHA256SUMS-verified v0.2.0 release binary but owns the job graph, checking the project out at the workspace root. Recorded in [pixi-sandbox](./landscape/pixi-sandbox.md) and [GitHub Actions](./cicd/github-actions.md).
- **Phase 0 CI**: The scaffold's gates could not pass, and each failure is now fixed and verified by a green run: `xtask` was missing `license`/`repository`/`authors`, which `cargo deny check` reports as `unlicensed` even for `publish = false`; two transitive crates (`number_prefix`, `proc-macro-error2`) carry unmaintained advisories with no safe upgrade and are ignored by ID; `lint-docs` ran against `apps/pixi-skills-docs`, which is Phase 4 work, so it is now guarded by `hashFiles` like `docs-build`; and every TOML manifest lacked a trailing newline, which is what `taplo fmt --check` was reporting on all eleven files.
- **Scope**: The Python knowledge validator is gone — `scripts/check_knowledge.py`, `requirements-knowledge.txt` and `tests/` are no longer in the repository. The README's install-and-`unittest` instructions described files nobody can run, and the Dependabot `pip` ecosystem failed weekly on the missing requirements file; both are updated, and the `cargo` ecosystem is enabled now that `Cargo.toml` exists.
